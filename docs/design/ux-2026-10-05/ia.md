# 기능 배치 결정표 (IA) v1

상태: 2026-10-05 사용자 구현 지시를 받은 배치 기준
상위 문서: [화면 설계서](design-system.md) · [기능별 질문 지도](feature-questions.md)

새 기능은 코드보다 이 표에 먼저 들어온다. 줄마다 "어디에, 어떤 모양으로, 왜, 무엇을 밀어내는지"를 적는다. 표에 없는 기능은 화면에 만들지 않는다.

## 1. 내비게이션을 나누는 기준

| 기준                           | 내비                                |
| ------------------------------ | ----------------------------------- |
| 새로 올라온 것을 훑을 때       | **최신 글** `/`                     |
| 내가 도울 수 있는 것을 찾을 때 | **답을 기다리는 질문** `/questions` |
| 분야를 정해 차근차근 읽을 때   | **주제** `/resources`               |

전역 내비는 3개로 고정한다. 검색은 내비가 아니라 머리의 입력칸이다. 위키·강의·CTF가 생겨도 먼저 이 셋 중 하나의 구역이나 주제 길잡이로 넣고, 작업 방식(편집 이력·제출·채점)이 달라질 때만 4번째를 검토한다(조사 보고서 `docs/research/forum-organization-20261001/report.md`의 "언제 게시판을 나눌 것인가" 기준).

## 2. 기능별 배치

| 기능                     | 위치                                              | 형태                                      | 이유                                       | 밀어내는 것                                              |
| ------------------------ | ------------------------------------------------- | ----------------------------------------- | ------------------------------------------ | -------------------------------------------------------- |
| 검색                     | 머리 입력칸(≥600) · 돋보기 → 전체 화면 시트(<600) | 입력 → `/?q=` 결과                        | 어느 화면에서나 한 번에                    | 목록 머리의 검색 폼(기존 `search-form`)                  |
| 글 목록                  | 최신 글 본문                                      | **답 미리보기 줄**(PostRow)               | 본문 중앙값 75자 → 목록에서 답이 읽힌다    | 표(`forum-table`)와 열 머리                              |
| 목적 필터                | 목록 제목 아래                                    | 칩 4개 + 개수                             | 질문·공유·자유로 좁히기(기존 결정 B 유지)  | 기존 탭 모양                                             |
| 편집 자료/회원 글 구분   | 줄 메타                                           | "2017년 10월 카톡 기록" / "이름 · n일 전" | 구분은 유지하되 330번 반복하는 배지를 없앰 | 줄마다 "자료편집 운영계정"                               |
| 기록 시기                | 줄 메타, 글 머리                                  | 원천 기간 문자열                          | 판단 근거는 웹 게시일이 아니라 기록 시기   | 줄의 웹 게시일                                           |
| 답 기다리는 질문         | 전역 내비 2번째 · PC 오른쪽 상자 5개              | 목록 + "답하기"                           | 질문 100개가 모두 답이 없다 → 참여 입구    | –                                                        |
| 길잡이                   | 주제 화면 위                                      | 카드 4개(대표 글 3 + 모두 보기)           | 운영자 선택 묶음(기존 자료 길잡이)         | 첫 화면의 "자료 길잡이" 탭                               |
| 주제 색인                | 주제 화면 아래                                    | 고정 입력칸 + 개수 칩, 1회 주제 접힘      | 표기 497개 중 383개가 1회                  | 오른쪽 주제 34개 세로 목록, 좁은 폭 "주제별로 찾기" 펼침 |
| 주제 표기 합치기         | 주제 색인·주제 목록·필터                          | 별칭 표 11묶음(표시 단계)                 | 리버싱/역공학 등 같은 말이 따로 셈         | –                                                        |
| 주제 상위 목록           | PC 오른쪽 상자                                    | 14개 + 모든 주제                          | 첫 화면에서 분야 감 잡기                   | 기존 긴 목록                                             |
| 글 본문                  | 글 화면                                           | 읽기 폭 720, §8 규칙                      | 기술 글 읽기                               | –                                                        |
| 출처·확인 내역           | 글 머리 "출처와 확인" 펼침                        | dl 5줄 + 정정·삭제 링크                   | 고지가 답보다 먼저 길게 보이지 않게        | 본문 위 고지 3줄 + "확인 내역"                           |
| 편집자 보충              | 본문 안                                           | 상자 + 출처 번호 목록                     | 기록 내용과 덧붙인 내용 구분               | 일반 h3 + "출처:" 한 줄                                  |

| 표                       | 본문 안                                           | 가로 스크롤 + 첫 열 고정                  | 레지스터·섹션 표                           | 기존 `markdown-table` 그대로 확장                        |
| 그림                     | 본문 안                                           | 크게 보기 시트                            | 디버거 화면                                | (업로드 기능 이후)                                       |
| 목차                     | PC 오른쪽 / 좁은 폭 접힘                          | h2 3개 이상                               | 긴 글                                      | –                                                        |
| 함께 읽을 글             | 글 아래                                           | 제목 + 미리보기                           | 중복 판정이 확인한 연결(기존)              | –                                                        |
| 같은 주제의 글           | 글 아래                                           | 3개                                       | 330개 짧은 글을 이어 읽는 주 경로          | –                                                        |

| 링크 복사                | 글 아래 행동 줄                                   | 버튼                                      | 카톡 공유가 주 유입                        | –                                                        |
| 신고·삭제 요청           | 글 아래 행동 줄 · 바닥글 · 출처 펼침              | 링크                                      | GOAL 보존 항목                             | –                                                        |
| 글 쓰기                  | 머리(≥1024) · 목록 제목 옆(<1024)                 | 주 버튼 1개                               | 화면당 주 버튼 하나                        | 중복 버튼                                                |
| 비슷한 글 먼저 보기      | 글쓰기 제목 아래                                  | 상위 3 링크, 막지 않음                    | 중복 보류 전에 스스로 확인                 | –                                                        |

| 주제 제안·합침 안내      | 글쓰기 주제 입력 아래                             | 기존 주제 + 개수                          | 표기 분산을 입력 단계에서 줄임             | –                                                        |

## 3. 만들지 않는 것 (이번)

| 기능                       | 이유                                  |
| -------------------------- | ------------------------------------- |
| 태그 구름 전체를 첫 화면에 | 1회 주제가 77% → 소음                 |
| 인기순·추천순              | 회원 활동 0, 근거 없는 순위           |
| 원본 카톡 검색·대화 보기   | 원자료 비공개 원칙                    |
| 채택 답변·투표·알림        | 데이터 모델 없음, 활동 확인 후        |
| 별도 AI 게시판             | 조사 결론: AI는 주제·목적과 겹친다    |
| 무한 스크롤                | 페이지 주소·복귀 위치·사이트맵과 충돌 |
