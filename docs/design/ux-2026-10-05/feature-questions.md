# 기능별 질문 지도 v1

상태: 2026-10-05 사용자 구현 지시를 받은 질문 지도 · 상위 문서: [화면 설계서](design-system.md)

## 이 문서의 규칙

1. **누가, 언제 보나**를 하나로 좁힌다.
2. 그 사람이 **실제로 묻는 질문**을 자주 묻는 순서로 적는다.
3. 질문마다 **답의 형태**(문장, 목록, 개수, 펼침, 코드)를 정한다.
4. 1번 질문의 답이 그 화면에서 가장 크고 가장 위에 온다. 답할 수 없는 질문은 "왜 없는지"를 한 줄로만 적는다.
5. 질문에 답하지 않는 요소는 넣지 않는다.

---

## 1. 글 목록 (최신 글·주제·검색)

**누가, 언제**: 검색이나 내비로 들어와 무엇을 읽을지 고르는 사람(30초~2분).

| 순위 | 질문                        | 답의 형태                  | 화면          |
| ---- | --------------------------- | -------------------------- | ------------- |
| 1    | 이 글이 내가 찾는 답인가?   | 제목 + **답 미리보기 3줄** | PostRow 본문  |
| 2    | 질문인가, 설명인가?         | 목적 라벨 한 단어          | 줄 맨 위      |
| 3    | 언제 얘기인가? 지금도 맞나? | "2018년 11월 카톡 기록"    | 메타          |
| 4    | 무슨 분야인가?              | 주제 3개(누르면 그 주제)   | 메타          |
| 5    | 답이 달렸나?                | "답 기다림" / "답변 n"     | 줄 맨 위      |
| 6    | 공개 문서 근거가 있나?      | "보충 출처 n"              | 메타          |
| 7    | 몇 개나 있나?               | "공개 글 330개"            | 목록 위 한 줄 |

버리는 것: 작성자 배지 반복, 웹 게시일, "댓글 0".

## 2. 글 화면

**누가, 언제**: 검색엔진·카톡 링크로 바로 들어온 사람(30초~5분).

| 순위 | 질문                           | 답의 형태                                             | 화면                          |
| ---- | ------------------------------ | ----------------------------------------------------- | ----------------------------- |
| 1    | 답이 뭔가?                     | 본문(첫 화면 안에 시작)                               | 제목 바로 아래                |
| 2    | 누가, 언제 한 얘기인가?        | "자료편집 운영계정 · 2017년 10월 카톡 기록"           | 머리 한 줄                    |
| 3    | 믿어도 되나? 어디서 확인했나?  | 편집자 보충 상자 + 출처 번호 목록, "출처와 확인" 펼침 | 본문 안·머리                  |
| 4    | 코드를 그대로 쓸 수 있나?      | 복사 버튼, 줄바꿈, 바이트 열                          | 코드 머리줄                   |
| 5    | 다음에 뭘 읽지?                | 함께 읽을 글 · 같은 주제의 글 3개                     | 본문 아래                     |
| 6    | 내가 보충·정정할 수 있나?      | 답변·댓글 쓰기(비회원은 로그인 버튼)                  | 맨 아래(질문 글은 연관 글 위) |
| 7    | 잘못됐거나 내 대화가 쓰였으면? | 글 신고·삭제 요청, 정정·삭제 요청                     | 행동 줄·출처 펼침             |

## 3. 답을 기다리는 질문

**누가, 언제**: 도움을 줄 수 있는 실무자·학습자(저녁, 5~15분).

| 순위 | 질문                              | 답의 형태                                              |
| ---- | --------------------------------- | ------------------------------------------------------ |
| 1    | 내가 답할 수 있는 질문이 있나?    | 질문 본문 미리보기 + 주제                              |
| 2    | 내 분야(IDA·Windows…)만 보고 싶다 | 주제 칩(질문에 많이 붙은 8개)                          |
| 3    | 얼마나 쌓였나?                    | "100개"                                                |
| 4    | 바로 답할 수 있나?                | 줄마다 "답하기" → 답변 쓰기                            |
| 5    | 오래된 질문에 답해도 되나?        | 메타의 기록 시기 + 소개 문장("한 줄 답도 도움이 돼요") |

## 4. 주제

**누가, 언제**: 분야를 정해 읽으려는 입문자(주말, 10분 이상), 특정 도구만 보려는 사람.

| 순위 | 질문                               | 답의 형태                                                            |
| ---- | ---------------------------------- | -------------------------------------------------------------------- |
| 1    | 어디서 시작하지?                   | 길잡이 4개(설명 + 대표 글 3)                                         |
| 2    | ○○(PE, 패킹) 글만 보고 싶다        | 주제 이름 찾기 입력 → 바로 아래 색인                                 |
| 3    | 어느 주제에 글이 많나?             | 개수 많은 순                                                         |
| 4    | "역공학"과 "리버싱"이 다른가?      | 합쳐 보이고, 합친 표기를 한 줄로 밝힘                                |
| 5    | 길잡이는 누가 골랐나, 믿어도 되나? | "운영자가 공개 글을 확인하고 묶었어요 · 정확성 인증 목록은 아니에요" |

## 5. 검색

| 순위 | 질문                   | 답의 형태                                                     |
| ---- | ---------------------- | ------------------------------------------------------------- |
| 1    | 찾는 게 있나?          | 관련도순 목록 + 일치 부분 표시                                |
| 2    | 이 말이 주제 이름인가? | "#IAT 주제 글 7개 모두 보기"                                  |
| 3    | 없으면 어떻게 하지?    | "‘Ghidra’로 질문하기"(제목 채움) · 모든 주제 · 자주 찾는 주제 |

## 6. 글 쓰기

**누가, 언제**: 막혀서 질문하거나 분석을 남기려는 회원(PC, 5~20분).

| 순위 | 질문                             | 답의 형태                                          |
| ---- | -------------------------------- | -------------------------------------------------- |
| 1    | 무엇을 쓰면 답을 잘 받나?        | 목적별 안내 한 줄                                  |
| 2    | 이미 같은 질문이 있나?           | 제목 아래 비슷한 글 3                              |
| 3    | 코드·디스어셈블리를 어떻게 넣나? | 넣기 버튼 + 미리보기                               |
| 4    | 어떤 주제를 붙이나?              | 기존 주제 제안 + 표기 합침 안내                    |
| 5    | 등록하면 바로 보이나?            | "비공개로 저장되고, 기본 확인을 통과하면 공개돼요" |
| 6    | 무엇을 올리면 안 되나?           | 대화 원문·개인 정보·치트 배포 링크 한 줄           |

## 7. 내 글

| 순위 | 질문                           | 답의 형태                                 |
| ---- | ------------------------------ | ----------------------------------------- |
| 1    | 내 글이 공개됐나?              | 상태 단어(공개·확인 중·공개 보류)         |
| 2    | 왜 보류됐나? 어떻게 하면 되나? | 사유 문장 + 관련 글 + 수정·다시 확인 요청 |
| 3    | 답이 달렸나?                   | 답변 n                                    |
