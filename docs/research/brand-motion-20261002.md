# Reversing All 로고 연출과 검토 기록

2026년 10월 2일. Reversing All 전체를 글자별로 뒤집고 복귀하는 8.4초 루프를 구현했습니다. 기본 이름이 가장 오래 읽히면서 움직임이 이어집니다. 사용자 후속 결정에 따라 OS 동작 줄이기 대응을 제거했습니다.

## 참고한 제작 방법

Maplestory의 영상 구조 문서가 가리키는 [기존 제작 조사](C:/_projects/research/media/promotional-video/README.md)와 [모션 인포그래픽 조사](C:/_projects/research/media/motion-infographics/motion-infographics-research-20260912.md)를 읽었습니다. 전자는 X 중심 조사이며 Threads를 조사하지 않았다고 명시합니다. 관련 경로에서도 이번 로고에 적용할 별도의 Threads 자료는 찾지 못했습니다.

[Cursor 브랜드 모션 영상](https://x.com/junaiddshaukat/status/2102509031260852454)은 Maplestory에 보관된 20초 MP4로 확인했습니다. 심벌 조각이 모이고 이름이 나타납니다. 작성자는 SVG를 가져와 Blender에서 제작하고 미리보기와 최종 영상을 출력했다고 설명합니다. 제작 모델과 비용은 작성자 주장으로 구분합니다. 이번 구현에는 요소를 나누어 시간표로 조립하고 출력을 검토하는 방법을 참고했습니다.

단어 전체를 가운데 축으로 돌리는 안을 교체하기 전에 다음 제작 자료를 조사했습니다. 아래 적용 판단은 이 로고의 크기와 사용자 요청을 기준으로 한 판단입니다.

| 자료                                                                                                                                  | 확인한 방법                                                           | 적용 판단                                                    |
| ------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------ |
| [Animated Opening Type](https://tympanus.net/codrops/2013/11/14/animated-opening-type/)                                               | 글자마다 회전축과 여러 면을 구성해 여닫는 3D 효과를 설명합니다.       | 글자의 앞·뒷면과 개별 회전축을 구성하는 방법을 참고했습니다. |
| [Osmo의 SplitText 예제](https://tympanus.net/codrops/2025/05/14/from-splittext-to-morphsvg-5-creative-demos-using-free-gsap-plugins/) | 문자를 나누고 지연·이동·맞춤 가속 곡선을 조합합니다.                  | 옆 글자로 동작이 이어지는 시간표를 참고했습니다.             |
| [Decorative Letter Animations](https://tympanus.net/codrops/2018/01/10/decorative-letter-animations/)                                 | 글자와 장식 도형의 등장·퇴장에 서로 다른 시간표를 적용합니다.         | 헤더에는 글자와 작은 선 강조를 사용하기로 정했습니다.        |
| [Google Web Designer의 텍스트 효과](https://support.google.com/webdesigner/answer/12414715?hl=en)                                     | 글자별 회전·이동, 겹쳐 시작하는 시점, 방향, 역방향 재생을 설정합니다. | 전진과 복귀를 하나의 시간표에 넣는 구성을 확인했습니다.      |

최종 선택은 글자의 앞·뒷면을 짧은 곡선 이동과 함께 넘기는 연출입니다. 순서가 바뀐 글자를 각 뒷면에 미리 배치해 전체 이름의 거울상을 만듭니다. 글자를 다른 글자의 자리까지 길게 이동시키지 않아 좁은 헤더에서도 경로가 복잡하게 겹치지 않습니다. 이는 참고 자료를 이 로고에 맞게 조합한 구현입니다.

## 적용한 연출

| 시간        | 보이는 동작                                                                           |
| ----------- | ------------------------------------------------------------------------------------- |
| 0–1.95초    | 기본 이름을 보여주면서 작은 글자 파동과 심벌의 선 강조가 이어집니다.                  |
| 1.95–3.44초 | 왼쪽에서 오른쪽으로 글자가 곡선 이동과 힌지 회전을 거쳐 뒷면으로 넘어갑니다.          |
| 3.44–3.82초 | 전체 이름의 거울상이 잠시 보입니다.                                                   |
| 3.82–5.31초 | 오른쪽에서 왼쪽으로 글자가 반대 곡선을 따라 앞면으로 복귀합니다.                      |
| 5.31–8.4초  | 기본 이름을 보여주면서 선 강조와 작은 글자 파동이 이어집니다. 시작 상태로 연결됩니다. |

기본 방향의 이름이 보이는 구간은 합계 5.04초입니다. 나머지 구간은 순차 회전·뒤집힌 상태·복귀로 나뉩니다. 글자가 회전하는 동안에도 나머지 글자는 유지됩니다. 완전히 정지한 대기는 약 0.35초입니다.

요소별 애니메이션은 하나의 시작 시점과 8.4초 주기를 공유합니다. 글자별 출발 시점은 45ms 간격이며 단어 전체에는 회전 애니메이션을 적용하지 않습니다. 왼쪽 심벌을 누르면 재생하거나 정지합니다. 정지하면 기본 로고로 돌아오며 선택을 브라우저에 저장합니다. 브라우저 탭을 숨기면 재생도 멈춥니다. OS 동작 줄이기 설정과 관계없이 같은 연출을 재생합니다.

웹에서는 글자와 SVG를 [Web Animations API](https://developer.mozilla.org/en-US/docs/Web/API/Element/animate)로 제어합니다. [currentTime](https://developer.mozilla.org/en-US/docs/Web/API/Animation/currentTime)으로 시점을 재현해 같은 시간표에서 PNG와 MP4를 출력합니다. 실제 웹 로고는 벡터와 텍스트를 직접 재생하며 영상은 연출 검토본으로 제공합니다.

## 검토와 재현

```sh
node scripts/review-brand-motion.mjs --render
```

실제 미리보기 앱을 헤드리스로 열어 확인합니다. 게시물이나 DB를 수정하지 않습니다. 결과는 Git에서 제외하는 `data/brand-motion/`에 기록합니다.

- 320·390·1440px와 OS 동작 줄이기 설정 두 가지에서 주기를 0.1초 간격으로 확인했습니다. 각 조합 85개 시점에서 화면 넘침, 헤더 밖의 글자, 계정 버튼 침범이 없었습니다.
- 두 OS 설정에서 각각 9초간 재생해 같은 글자별 회전과 연속적인 중간 상태를 확인했습니다. 콘솔 오류와 페이지 오류는 없었습니다.
- 회전 중에 정지해 기본 이름으로 돌아오는지 확인했습니다. 새로고침 후에도 정지 선택이 유지됐습니다.
- 실제 헤더와 확대 프레임을 확인했습니다. MP4는 같은 DOM과 시간표에서 만든 960×288, 60fps, 504프레임, 8.4초 검토본입니다.
- 렌더에 사용한 첫 번째 PNG와 마지막 PNG의 SHA-256 해시가 같습니다. 루프 경계의 기본 로고가 같은 이미지로 이어집니다.

확인 파일은 `verification.json`, `header-320-no-preference.png`, `header-320-turn.png`, `final-sheet.png`, `reversing-all-loop.mp4`입니다. 이 검토는 Chromium과 현재 PC의 글꼴 환경에서 수행했습니다. 다른 브라우저의 글꼴 렌더링과 사용자가 판단하는 연출의 완성도는 별도 확인이 필요합니다.
