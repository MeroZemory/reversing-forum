## 저장소에서 확인한 출발점

- `src/server/forum.ts`의 일반 글 작성은 실제 회원을 전제로 비공개 저장 후 Jev 결과로 공개 상태를 갱신합니다. 편집 초안·추가 승인·게시 영수증은 아직 없습니다.
- `src/server/jev.ts`의 현재 질문은 spam·harassment·privacy입니다. 오류는 공개하지 않는 방향으로 처리합니다. 응답의 실제 모델·사용량·검사 해시를 모두 보관하는 어댑터는 후속 구현입니다.
- `src/server/db.ts`의 글 상태는 pending·published·held입니다. 공개 목록·주제·댓글·메타데이터의 기존 제한은 새 편집 경로에서도 유지해야 합니다.
- `src/server/screens.ts`와 화면 데이터 계약은 내부 Jev 근거를 공개 응답에서 제외합니다. 새 출처·주장 상태의 공개 필드도 허용 목록으로 추가해야 합니다.
- 파일 목록과 길이만 다시 확인한 루트 백업 5개의 합계는 **46,521,020바이트**입니다. 기존 보고서의 약 37MB 표기를 실제 파일 합계인 약 46.5MB로 수정했습니다. 이번 계획 작업에서 원문을 추가로 외부에 전달하지 않았습니다.

기존 앱에 대해 typecheck, Vitest 6개 파일의 61개 테스트, 별도 `.next-verification` 디렉터리의 production build가 통과했습니다. 이 확인은 현재 앱에 대한 회귀 검사이며, 아직 구현하지 않은 파이프라인의 시험 결과가 아닙니다.
