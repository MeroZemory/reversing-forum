# 포럼 구조 독립 검수와 반영 결과

2026년 10월 1일, 사용자가 요청한 GPT-6 Astra/max와 GPT-6.1 Sol/max를 별도 검수 에이전트로 호출했습니다. 프로젝트나 전역 모델 설정은 변경하지 않았습니다. 두 검수자는 다른 역할을 맡아 같은 조사 초안을 검토했고, Sol 검수는 부모 작업이 반영한 수정본도 대조했습니다. 모델 검수는 실제 회원의 작성·탐색 시험을 대신하지 않습니다.

완성된 제안은 [조사 보고서](report.md), 외부 관찰과 확인 범위는 [출처](sources.md)에 있습니다. 원문 검수는 [Astra](reviews/astra.md)와 [Sol](reviews/sol.md)에서 확인할 수 있습니다. 원문 검수의 행 번호와 초안 인용은 당시 판본을 가리키며, 아래 표는 현재 보고서에 반영한 결과입니다.

## 현재 제안과 아직 선택하지 않은 것

현재 제안은 전체 공개 글을 함께 보는 경로를 유지하고, 답할 질문과 다시 쓸 자료를 쉽게 찾게 하는 것입니다. B의 목적 필터는 이를 구현하는 한 후보입니다. 소수 게시판으로 활동 공간을 분명히 하는 C와, 분류를 줄이는 A도 여전히 비교할 수 있습니다. 정리 자료를 첫 화면에서 얼마나 강조할지는 카톡과 웹의 역할 및 실제 준비된 자료를 기준으로 판단합니다.

당장 선택할 것은 세부 태그 체계가 아니라 첫 화면의 강조와 작성 위치입니다. AI 자료 안내는 어떤 안과도 결합할 수 있고, AI 검수·호출 봇과는 별개입니다. 게시판 분류·기존 글의 유형·공개 게이트는 이번 조사에서 변경하지 않았습니다.

가장 작은 공통 개선 후보는 **주제 하나로 찾기 → 검색으로 좁히기 → 읽기 → 같은 목록으로 복귀**입니다. 아직 구현된 기능으로 보고하지 않습니다. 필요한 작업은 [TODO](../../../TODO.md)에 연결했습니다.

## 이번에 실제로 확인한 것

조사자는 11개 포럼·플랫폼 사례를 공개 화면 또는 공식 기능 문서로 비교했고, UX와 크롤링 공식 설명을 별도로 읽었습니다. 공개 메뉴의 관찰과 플랫폼 기능의 문서 확인은 조사 범위가 다릅니다. 접근하지 못한 후보는 확인 사례에서 제외했습니다. Astra는 공식 문서 세 곳을, Sol은 공식 문서 두 곳과 현재 코드·설치된 Next.js 문서를 독립적으로 대조했습니다.

Reversing All 브랜드 변경은 별도 구현 작업으로 반영했습니다. 25초마다 1.5초간 로고 글자를 뒤집고 교차한 뒤 원복합니다. 화면 폭 320·390·1440px, 움직임 중 크기 유지, 두 주기의 지정 시점 샘플, 동작 줄이기 설정, 메타데이터와 콘솔 오류를 헤드리스로 확인했습니다. 실제 시간으로 장시간 사용한 회원 평가나 동작 빈도 선호 조사까지 완료했다는 뜻은 아닙니다.

현재 프로젝트에서 형 검사, 서버 테스트 13개, 관련 E2E 2개와 기본 빌드가 통과했습니다. 문서의 로컬 링크와 형식도 확인했습니다. 이는 브랜드 변경과 기존 흐름의 검증이며, 앞으로 제안한 정확한 태그·복귀·새 분류의 완료 증거가 아닙니다.
