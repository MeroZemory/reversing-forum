# 포럼 분류 조사 출처와 확인 범위

확인일은 2026년 10월 1일입니다. 실제 공개 메뉴를 관찰한 사례와 플랫폼의 공식 기능 문서를 구분했습니다. 게시판 수, 가입자 수, 누적 글 수를 성공의 원인이나 우리 서비스의 분할 기준으로 사용하지 않습니다. 각 사례의 적용 가능성은 [조사 보고서](report.md)에 별도로 판단합니다.

| 목적과 주제를 섞는 게시판은 항상 잘못된 구조입니다.           | 단정이 틀렸습니다.             | Discourse Meta·Chess.com·Arch Linux에 혼합 기준이 실제로 있습니다. 혼합이 우리 회원에게도 이해하기 쉬운지는 별도로 확인해야 합니다.                              |

## 확인하지 못한 후보

Fountain Pen Network, BoardGameGeek, AVS Forum, The Gear Page, Watchuseek, DISboards, FM Korea, Clien, Ruliweb 및 DPReview 포럼 인덱스는 수집 과정에서 접근 실패 또는 접근 제한이 있었습니다. 구조를 확인한 사례 수에 포함하지 않았고, 우회 수집하지 않았습니다. DPReview의 검색 결과에는 과거 메뉴가 있었지만 현재 구조라고 단정할 수 없어 비교에서 제외했습니다.

## 로컬 프로젝트 확인

- `src/lib/types.ts`의 글 유형은 자유·질문·분석·AI 활용입니다. 한 글은 한 유형을 가집니다.
- `src/app/page.tsx`의 유형 메뉴는 같은 글 목록의 조건을 바꿉니다. 독립 게시판이나 서로 다른 권한 공간이 구현된 상태는 아닙니다.
- `src/server/forum.ts`의 공개 목록은 `published`만 조회합니다. 검색은 제목·본문·태그 JSON의 부분 문자열을 조회하며, 태그의 정확한 일치나 복수 태그 필터는 아직 없습니다.
- 현재 기본 목록은 작성 시각순이며 기본 조회 한도는 30개입니다. 댓글이 달렸다고 자동으로 상단에 올라오는 목록이 아닙니다.
- `src/app/sitemap.ts`는 1,000개를 요청하지만 `listPosts`가 최대 100개로 제한합니다. 현재 사이트맵이 모든 공개 글을 포함한다는 주장은 하지 않습니다.
- 질문 해결 상태, 상세 AI 팩트체크, 위키 편집 이력, 주제 팔로우는 아직 구현되지 않았습니다.

최신 카톡 백업에서는 도구 사용 질문, 입문 환경, 악성코드 분석, AI 답변 검증 및 CTF 관련 논의를 키워드로 일부 확인했습니다. 이는 분류가 겹치는 상황을 찾기 위한 목적 표본이며, 전체 방의 주제 비율이나 활동량을 추정한 분석이 아닙니다. 시점이 다른 백업의 중복이나 닉네임 변경을 해결한 통계도 아닙니다. 원문과 닉네임은 이 문서나 검수 에이전트에 전달하지 않습니다.
