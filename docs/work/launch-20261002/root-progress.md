## 2026-10-03 초기 진행 기록

이 절의 검사 수와 공개 글 수는 품질 재검토 전의 기록입니다. 현재 결과는 다음 절에 적습니다.

Sol/max·Astra/max의 상호 검토 합의에 따라 공통 글 목록·자료 길잡이, 공개 글 전체를 대상으로 한 의미 중복 확인, 스팸 제한과 게시 직전 동시성 확인을 구현했습니다. 불확실·오류·예산 초과는 비공개를 유지하며, 확인된 공개 연관 글만 표시합니다. [합의 기록](consensus.md)

이메일 인증·재전송·복구와 Google 가입·사이트 닉네임 설정·명시적인 다른 이메일 연결·해제·비밀번호 설정을 구현했습니다. 로그인과 가입 화면의 중복 동선을 정리하고 작은 화면의 계정 메뉴를 개선했습니다. 공급자 페이지로의 실제 Google 이동은 확인했지만 실제 Google 인증 완료와 Resend 메일 수신은 아직 확인하지 않았습니다.

전체 원본 범위 대응은 끝났으며 후보 추출·편집·독립 검토·실제 게시를 계속 실행합니다. 원본 범위 대응이나 출력 가져오기 수를 전체 의미 검토 완료로 표현하지 않습니다. 잘못된 범위·분류가 충돌한 출력은 비공개로 보존하며 새 모델 결과로 복구합니다. 확정 보류 판정을 같은 글의 재게시로 초기화하지 않고, 승인된 같은 최종본의 재시도는 기존 승인·시도 횟수를 유지하도록 수정했습니다.

타입 검사·빌드와 서버 테스트 473개가 통과했습니다. 모델·빌드의 병렬 실행과 테스트가 자원을 함께 사용해 일부 실행 시간 제한을 초과했으며, 서버 검증의 동시 작업을 두 개로 제한해 전체 통과를 확인했습니다. 대량 파싱의 성능 기준은 유지했습니다. 헤드리스 화면 검수 66개에서 가로 넘침·콘솔 오류가 없었고, 자료 길잡이의 탐색·복귀·댓글·비공개 접근 검증도 통과했습니다. 전체 브라우저 시나리오 15개도 한 실행에서 모두 통과했습니다. [검증 범위](verification.md)

실제 서버의 현재 공개 글은 23개입니다. 같은 승인본의 재게시를 실제 검수·공개 경로로 확인했습니다. 응답을 끝내지 않는 추출 호출 네 개를 확인해 해당 프로세스만 종료하고, 완료한 기록과 비용 예약은 보존한 채 재개했습니다. 새 호출은 후보 추출 10분·편집 15분·독립 검토 20분의 최대 실행 시간을 적용합니다. 미확인 비용 예약을 삭제해 예산을 늘리지 않습니다.

Cloudflare 전용 터널 생성은 현재 토큰으로 `403 / 10000`을 반환합니다. 실제 배포·DNS 연결은 완료되지 않았습니다. 운영 스크립트는 고정 공개 주소와 별도 내부 포트를 지원하도록 준비했습니다. 도메인을 연결한 뒤 인증 콜백·영속 DB·외부 작성·재시작을 실제로 확인해야 합니다.

원본 대화·처리 근거·작업 DB·메일과 OAuth 비밀값은 비공개 로컬 파일에만 보관하며 커밋하지 않습니다. 자료 가공 호출은 기존 실행별 예산 장부로 집계하고 Jev 10달러·Codex 추산 한도를 유지합니다.

## 2026-10-03 품질 기준 변경과 호출 복구

기존 계정으로 자료 처리를 다시 실행할 수 있게 했습니다. 구독 사용률만으로 호출을 차단하던 코드를 수정했고, 같은 계정의 실제 호출이 정상 완료됐습니다. 사용자가 크레딧 사용을 명시한 설정에서도 배치 자체의 사용량 상한과 공급자의 실제 응답을 적용합니다. 앞선 계정 변경 요청은 필요하지 않았습니다.

공개 자료 30개 가운데 18개를 보류했습니다. 대상이나 문제를 알 수 없는 글, 근거가 부족한 글, 쓸 정보보다 대화 경과를 나열한 글을 제외했습니다. 나머지 12개는 개념·조건·방법을 직접 설명하는 자료로 다시 작성했습니다. 독립 검토에서 원자료에 없는 설명이 발견된 한 글은 해당 설명을 제거한 뒤 새 검토를 통과했습니다. 실제 게시 검수에서는 10개가 갱신됐고 2개는 보류됐습니다. 현재 공개 글은 10개입니다. 원자료·기존 버전·처리 기록은 비공개로 보존합니다.

새 품질 기준은 이전 승인과 구분하며 같은 최종본에 대한 통과가 필요합니다. 보류 글은 새 버전의 검토·승인·최종 검수를 거쳐 복구할 수 있습니다. 오래된 배치 출력 형식이 새 품질 항목을 빠뜨리는 문제도 발견해, 새 작업이 현재 형식을 쓰도록 수정했습니다. 빠진 항목을 코드로 통과 처리하지 않았습니다.

전체 서버 테스트 555개와 타입 검사·빌드가 통과했습니다. 갱신된 첫 화면·자료 길잡이·글 화면을 세 가지 폭에서 확인했고 가로 넘침·콘솔 오류·비공개 근거 노출이 없었습니다. 보류된 20개 글의 직접 주소는 비회원에게 모두 차단됐습니다. 전체 자료 처리와 외부 배포는 미완료입니다. Cloudflare 권한 문제, 실제 메일 수신과 Google 로그인 완료가 남아 있습니다.

실제 DB의 격리된 복사본으로 백업·복구도 확인했습니다. 복사본의 변경을 되돌린 뒤 전체 내용과 구조가 기준 시점의 원본과 일치했고, 아직 DB 본체 파일에 반영되지 않은 기록도 백업에 포함됐습니다. 원본 DB를 수정하거나 앱을 중지하지 않았습니다. 외부 운영 서버의 재시작·원격 복구는 별도로 확인해야 합니다.

ReTalk의 허용된 PC 카톡 대화방에 읽기 전용으로 연결했습니다. 검색한 2017년 예외·디버거 기록은 나오지 않았고, 최근 예외 관련 대화는 다른 분석 맥락이었습니다. 다른 시기의 대화를 해당 사례의 근거로 합치지 않았습니다.

질문·공유·자유는 첫 구현의 작성 목적 필터입니다. 별도 게시판을 늘리지 않고 최신 글과 자료 길잡이가 같은 글을 사용하는 기존 합의를 유지합니다. 영구적인 분류 체계로 확정하지 않았습니다.
