메일 회귀 검증에는 격리한 테스트 전용 수신함을 사용합니다. 데이터베이스의 인증 값을 직접 바꾸지 않습니다. 브라우저 검증의 Jev·중복 응답은 테스트 전용 데이터베이스에서만 사용할 수 있으며 운영과 일반 로컬 데이터베이스에서는 무시합니다. 일부 테스트가 의도적으로 만드는 본문 hydration 오류와 잘못된 입력은 해당 오류가 계속 감지되는지 확인하기 위한 것입니다.

병렬 빌드·모델 호출과 검증이 함께 실행된 일부 시도에서는 프로세스 시작·대량 자료 준비의 실행 시간 제한을 넘었습니다. 최종 검증은 서버 테스트의 동시 작업을 두 개로 줄였습니다. 프로세스 간 예산 예약과 대형 복구의 개별 시간 제한을 15초로 정했고, 원본 5만 메시지 준비의 20초 성능 조건은 유지했습니다.

## 실제 공급자·자료 실행

로컬 비양자화 임베딩과 실제 Jev·Codex CLI의 중복 판정으로 한국어 재표현·재배열·짜깁기를 중복으로, 새 조건·정정·다른 실패 조건·공통 코드에 새 설명을 더한 사례를 허용하는 결과를 각각 확인했습니다. 계정 조회 시간이 초과된 한 사례는 별도 재실행에서 통과했습니다. 일곱 사례가 모두 통과한 단일 실행 기록으로 표현하지 않습니다. 독립 Sol/medium 재확인도 실제 실행에서 확인했습니다. 이 작은 표본이 전체 한국어 리버싱 글의 정확도를 보장하지 않습니다.

기존 같은 승인본의 게시 재시도에서는 승인·시도 횟수를 유지하고 실제 최종 Jev·중복·공개 비교 자료 확인을 다시 거쳤습니다. 확정된 보류는 같은 본문의 수정·재승인으로 초기화하지 않습니다. 현재 공개 글은 23개이며 이후 가공·게시로 달라질 수 있습니다. 누적 게시 영수증 수는 현재 공개 글 수와 다릅니다.

최소화 후보의 실제 추출과 Luna/max 편집·Sol 6.1/xhigh 독립 검토를 계속 실행합니다. 분류가 충돌하거나 범위가 잘못된 결과는 비공개로 보존합니다. 같은 근거가 후보와 추가 문맥 대상으로 모두 표시되더라도 두 판단이 모두 미해결인 경우에만 중복 표시를 정리합니다. 원래 바이트와 정리 기록을 보존하며 미해결 항목을 검토 완료나 공개 후보로 승격하지 않습니다. 그 외 충돌은 거부하고, 선택한 재시도 횟수 내에서 실제 새 모델 결과만 사용합니다.

Google 공급자 페이지로의 실제 이동에서 올바른 클라이언트·콜백·state·PKCE 구성을 확인했습니다. 실제 Google 로그인 완료와 운영 콜백의 등록 상태는 확인하지 않았습니다. Resend의 제한된 발송 키로 도메인 목록 조회는 허용되지 않았으며 실제 메일 수신도 확인하지 않았습니다.

## 남은 실제 운영 확인

- 나머지 전체 후보의 가공·검토·게시와 미해결·보류 범위에 대한 최종 집계를 마쳐야 합니다.
- Cloudflare 터널 생성의 `403 / 10000` 권한 오류를 해결한 후 DNS·외부 HTTPS·실제 세션·영속 저장·재시작을 확인해야 합니다.
- 실제 메일 수신과 Google 인증 완료를 확인해야 합니다.
- 운영 자료 백업과 복구를 실제로 실행해야 합니다. 초기 SQLite 복사 스크립트를 구현한 사실만으로 복구 검증을 완료 처리하지 않습니다.
